# 한국어 표시 규칙

사용자에게 보이는 발언, 진행 상태, 결론은 모두 쉽고 자연스러운 한국어로 쓴다. 판단에 영향을 주지 않는 중간 과정은 보여주지 않는다.

## 보여줄 내용

- 쟁점, 근거, 반론, 불확실성, 결론처럼 판단에 필요한 내용만 시간순으로 짧게 보여준다.
- 역할을 표시할 때는 진행자, 제안자, 반대 검토자, 사실 확인자, 판단 담당자처럼 한국어 이름을 쓴다.
- 최종 정리에는 권고안, 이유, 제외한 대안, 남은 불확실성, 다음 행동을 포함한다.

## 보여주지 않을 내용

- 영어 역할명과 영어 상태명
- 내부 식별자, 점수, 데이터 필드, 시스템 이벤트 이름
- 작업 로그, 호출 정보, 모델 이름, 사용자에게 의미 없는 측정값
- 설명 없이 남은 영문 문장

코드, 제품명, 사용자가 제공한 원문처럼 꼭 인용해야 하는 표현은 유지할 수 있다. 그 밖의 설명 문장과 상태 문구는 한국어로 다시 쓴다. 이견이 남았을 때는 합의된 것처럼 표현하지 않는다.
